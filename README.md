# NeerWanna × Hotel Monalisa review demo

## Files
- `index.html` — complete responsive review experience
- `assets/neerwanna-logo.png` — NeerWanna logo
- `assets/hotel-monalisa-logo.jpg` — cropped logo/banner from the screenshot provided

## Publish on GitHub Pages
1. Upload `index.html` and the `assets` folder to your repository (keep the folder structure).
2. Commit the files to your Pages publishing branch.
3. Open the deployed page on a phone and test all three languages.

## Important demo notes
- The Google Maps destination is the shortened link supplied in chat. Verify that it opens the correct Hotel Monalisa listing before public use.
- The Maps link may open the listing rather than directly opening the review composer. The customer may need to tap Reviews / Write a review.
- This demo uses local JavaScript templates; it does not require an AI API key or backend.
- Review text is based on the selected answers and is editable before copying. Customers submit it themselves.
- For a production launch, replace the cropped Hotel Monalisa image with a clean official logo file if available.
